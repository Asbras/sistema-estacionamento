# Requisitos do Projeto

## Requisitos funcionais e técnicos

- Aplicação desenvolvida em Python.
- Mínimo de 10 interfaces (UI).
- Mínimo de 3 tabelas no banco de dados.
- Para cada tabela, implementar no mínimo 3 operações entre:
  - Insert
  - Update
  - Delete
  - Select
- Login obrigatório.
- Menu obrigatório.
- Tela "Sobre" obrigatória.
- Exportar todos os dados da aplicação para JSON.
- Compactar o JSON exportado em formato ZIP.
- Importar dados disponibilizados em um endereço Web usando `requests` ou `urllib`.
- Armazenar os dados importados em uma tabela.
- Exibir os dados importados em uma UI.
